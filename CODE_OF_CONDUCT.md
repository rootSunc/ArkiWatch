# Code of Conduct

ArkiWatch is a small, public-interest project. We want contributions and
discussions to be welcoming, practical, and respectful.

We expect participants to:

- focus on the work and assume good intent;
- welcome different backgrounds and levels of experience;
- give specific, kind, and actionable feedback;
- respect privacy, licensing, and the people represented by public data; and
- accept correction when an error or harmful assumption is identified.

Harassment, discrimination, threats, personal attacks, doxxing, spam, and
deliberate disruption are not acceptable. Project maintainers may edit, close, or
remove contributions that violate this standard and may restrict participation
when necessary to keep the project safe.

Report conduct concerns privately to the repository maintainers through GitHub.
Please do not include sensitive personal information in a public issue.
